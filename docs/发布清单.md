## 3. 构建前

```bash
npm ci
./scripts/fetch_pdfium.sh                 # Windows: pwsh scripts/fetch_pdfium.ps1
# 确认 src-tauri/resources/models 下的 det.onnx / rec.onnx / keys.txt 已提交（约 13MB，已入库）
git ls-files src-tauri/resources/models
# 应包含：det.onnx、rec.onnx、keys.txt、ner/ner.onnx、ner/vocab.txt
npm run build
cd src-tauri && cargo test && cargo clippy --all-targets
```

## 4. 打包与签名

- macOS Universal：`npm run tauri build -- --target universal-apple-darwin`；
  用 Developer ID 签名 + `notarytool` 公证 + `stapler` 装订；
- Windows：`npm run tauri build`；用代码签名证书签 `Luminar.exe` 与安装包；
- Windows 完整离线版：在标准包基础上把 WebView2 固定运行时放进
  `resources/WebView2Runtime/`，程序会自动检测并授予 AppContainer 读取权限；
- 同时上传 `.dmg`、标准 `*_portable.zip`、完整离线 `*_full_offline.zip` 与对应 `.sha256`。
