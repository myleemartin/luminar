# 星星脱敏 Mac 版打开说明

适用于 macOS 10.15 及以上（Intel）或 macOS 11 及以上（Apple Silicon）。

1. 双击下载的安装包 `Luminar_0.11.0_universal.dmg`。
2. 桌面上会出现一个名为 **「星星脱敏」** 的磁盘图标。
3. 双击这个磁盘图标，进入安装包窗口。
4. 在窗口里双击 **「星星脱敏.app」**，软件才会运行。
5. 第一次打开如果提示“无法验证开发者”，请在「星星脱敏.app」上右键 →「打开」；
   或到「系统设置 → 隐私与安全性」里点「仍要打开」。
6. 建议把「星星脱敏.app」拖到「Applications（应用程序）」文件夹，以后从启动台打开更方便。

> 注意：Mac 版不是双击 DMG 就直接运行；顺序是“双击 DMG → 桌面出现磁盘图标 → 双击磁盘图标 → 双击星星脱敏.app”。

## 支持的格式

`.docx` / `.docm` / `.doc` / `.wps` / PDF（文字版、扫描件）/ `.rtf` / `.ofd` / `.html` / `.htm` / `.txt` / `.md`

其中 `.doc` 使用内置 Word 97-2003 解析，大多数情况不需要额外安装；`.wps` 的二进制版本会先尝试原生解析，再回退 LibreOffice。
