# 参考来源与实现说明

> 本文回答两个问题：**哪些地方参考了别人的东西？参考到什么程度？**
> 结论先说：星星脱敏是独立的 Rust 实现，**没有复制任何第三方项目的源代码**；
> 参考集中在 OCR 算法流程、模型/字典数据、PDF 渲染库与若干产品设计思路。

## 2. OCR 部分参考了什么

### 2.1 PaddleOCR（Apache-2.0）

- 仓库：<https://github.com/PaddlePaddle/PaddleOCR>
- 参考内容：
  1. **DB 文本检测**的输出含义与二值化阈值（0.3）；
  2. **DB 后处理**：连通域 → 按面积/周长外扩（`unclip`）→ 文本框合并；
  3. **CRNN + CTC** 识别流程与 `blank` 索引约定；
  4. 识别输入尺寸（高 48）与归一化参数（均值/方差、`(x/255-0.5)/0.5`）；
  5. 中文字典 `ppocr_keys_v1.txt` 的字符集与顺序。
- 我们的实现差异：
  - 检测/识别均固定输入尺寸（960×960 / 48×960），用 letterbox + 右侧补零替代动态 shape；
  - 连通域使用并查集式 BFS，自行实现；文本框合并加了“同一行短间距合并”策略；
  - 置信度兼容两种模型输出（已 softmax / 未 softmax），做运行时判断；
  - 对 OCR 结果做全角→半角归一化，且保证字符数不变、坐标不偏移。

### 2.2 RapidOCR（Apache-2.0）

- 仓库：<https://github.com/RapidAI/RapidOCR>
- 参考内容：PP-OCR ONNX 模型的下载地址（Hugging Face `SWHL/RapidOCR`）、
  模型输入尺寸与字典组织方式；开发期用它作为 OCR 结果对照基线。
- 未复制其 Python 代码。

### 2.3 增强识别模型

- 模型：`IcyKallen/bert-mini-finetuned-ner-chinese`（Apache-2.0），
  6 层 / 288 维、PER/ORG/LOC 中文 NER，模型卡评估集 F1 约 0.87；
- 本项目用 ONNX Runtime 做 INT8 动态量化（`ner.onnx` 约 12 MB），
  推理用 `tract`，不依赖 Python/PyTorch；
- 参考内容：BIO 标签体系、BERT Chinese 分词方式；未复制上游代码或训练数据。

### 2.4 模型与字典

| 文件 | 来源 | 许可证 | 是否随仓库分发 |
| --- | --- | --- | --- |
| `assets/ppocr_keys_v1.txt` | PaddleOCR | Apache-2.0 | 是 |
| `det.onnx` / `rec.onnx` | RapidOCR 转换的 PP-OCR 模型 | Apache-2.0 | 是，随仓库与安装包分发 |
| `ner/ner.onnx` | `IcyKallen/bert-mini-finetuned-ner-chinese`（基座 `hfl/minirbt-h288`） | Apache-2.0 | 是，INT8 量化后随仓库与安装包分发 |
| `ner/vocab.txt` | BERT Chinese 词表 | Apache-2.0 | 是 |

## 3. PDF 部分

### 3.1 pdfium（BSD-3-Clause）

- 项目：<https://pdfium.googlesource.com/pdfium/>
- 用途：页面渲染、字符级坐标、扫描件栅格化。
- 分发：作为动态库随安装包分发（`libpdfium.dylib` / `pdfium.dll`）。
- 版权：`Copyright 2014 The PDFium Authors. All rights reserved.`

### 3.2 pdfium-binaries / pypdfium2

- <https://github.com/bblanchon/pdfium-binaries>、<https://github.com/pypdfium2-team/pypdfium2>
- 用途：仅用于获取 pdfium 官方编译产物；`scripts/fetch_pdfium.*` 只做下载与解压。

## 5. 测试样例

`tests/fixtures/` 下的 Word / PDF 均为**虚构内容**（人名、身份证号、卡号、案号均为编造），
仅用于自动化测试。样例在开发期由作者的本地脚本生成；该脚本依赖 PyMuPDF（AGPL-3.0），
**不包含在本仓库中**，发布物也不包含 PyMuPDF 的任何代码或二进制。

## 6. 字体与图标

- 界面只写系统字体名（PingFang SC、Songti SC、Microsoft YaHei 等），不嵌入字体文件；
- 图标由 `scripts/make_icons.py` 用纯 Python 绘制，未使用第三方素材。
